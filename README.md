# 育婴 · baby_care

一个完全离线的宝宝喂养记录 App：记录喝奶、排便和睡眠，查看每日汇总与趋势，并在下次喂奶时间提醒你。所有数据只保存在手机本地，不联网、不上传。

## 功能说明

### 今日记录

- **喝奶**：支持瓶喂与亲喂两种方式。
  - 瓶喂：填写喝奶时间、奶种（配方奶 / 母乳）、奶量（ml）和备注，提供 60/90/120/150ml 快捷奶量。
  - 亲喂：开始后实时计时，可切换左右侧、暂停 / 继续，结束时自动生成左右侧分段记录；也支持手动补录亲喂时长。
- **排便**：记录时间、颜色、性状与备注。
- **睡眠**：开始 / 结束实时计时，或手动补录起止时间；同一时间段的睡眠不允许重叠。
- 今日页展示瓶喂奶量、亲喂次数与时长、睡眠时长、排便次数四项汇总，以及按时间倒序的今日时间线，可点开任意记录编辑或删除。

### 喂奶提醒与状态栏

- 保存瓶喂时按奶量自动估算下次喂奶时间：`60 + 奶量` 分钟，限制在 90～240 分钟（例如 120ml 约 3 小时）。
- 提醒时间会显示在记录页的「喂奶提醒」卡片中，可点击手动调整、恢复建议时间，或只关闭这一条提醒。
- 亲喂结束或补录后默认按 3 小时设置提醒。
- 到点通过系统通知响铃提醒，App 被完全关闭也能准时触发（使用系统精确闹钟）。
- 常驻状态栏 / 锁屏通知展示「上次喝奶时间 · 下次时间 · 剩余时长」，每分钟自动刷新；到点后显示已超过多久。
- 可在「设置与备份 → 喂奶提醒」中分别开关到点闹钟与锁屏状态栏，并检查通知 / 精确闹钟权限。

### 统计

- 近 7 天趋势：瓶喂奶量、睡眠时长、排便次数。
- 每日汇总支持切换日期查看历史记录。

### 宝宝档案

- 支持创建多个宝宝档案（昵称、出生日期、性别、头像），随时切换当前宝宝。
- 各宝宝的记录完全隔离，删除宝宝会同时清理其全部记录。

### 数据备份与隐私

- 一键导出 / 恢复 JSON 备份文件（通过系统文件选择器保存和打开）。
- 恢复备份会覆盖当前全部数据，恢复前会要求先导出一份当前数据的安全备份。
- 应用完全离线运行，记录保存在应用私有目录，已关闭系统自动云备份。

## 统计口径

- 所有记录按北京时间（UTC+8，无夏令时）划分自然日。
- 睡眠、亲喂跨过零点时，按实际时长拆分到两天；次数归入开始日期。

## 技术说明

- Flutter（Dart SDK ^3.9.2），Material 3 主题，支持浅色 / 深色模式，界面语言为简体中文。
- 数据存储：SQLite（`sqflite`），数据库版本 2，`feeding_records.remind_at` 保存提醒时间，旧版本数据自动迁移。
- 提醒：`flutter_local_notifications` + `timezone`；状态栏倒计时由原生 Android 前台服务（`FeedStatusService`）每分钟刷新，数据在 App 退出后仍可展示。
